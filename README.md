# 雀帳｜台灣十六張麻將牌桌手帳

雀帳是適合手機操作的繁體中文麻將手帳。點選台型積木即可試算本局收付，也能拍下牌面、記錄點數，或輸入手牌查看聽牌與捨牌選擇。

[開啟雀帳網頁](https://kaluwei.github.io/quezhang-mahjong/)

## 使用方式

1. 在「牌桌總覽」設定底金、每台金額與本桌規則。選擇胡牌、自摸、放槍等結果，再點選成立的台型。
2. 檢查「本局結算」中的各家收付與重複計台提示，點「記錄本局」加入照片、點數和備註。已知實收金額時可用「快速輸入金額」。
3. 在「聽牌助手」點選萬、筒、條或字牌，也可輸入吃、碰、槓與場上明牌。16 張分析可胡的牌，17 張分析可進聽的捨牌。剩餘張數扣除已輸入的牌，是可能取得的上限。
4. 在「存檔管理」匯出 TXT。換手機時讀取舊檔即可繼續記帳，也可將舊檔與本機結果合併下載。重複匯入相同牌局會依紀錄識別碼去重。

## 開局助手與骰子特別玩法

在「開局助手」輸入四位牌友並抽風。使用實體風牌時，可擲抓位骰排出抽牌順序，再登記每張風牌的持有人。可約定東席起莊、指定莊家，或由東席另擲一次定莊骰。開門骰由莊家擲，可用畫面擲骰，也可輸入三顆實體骰。牌牆圖會標出第一手應拿的兩墩，包括跨牆的 17、18 點。

「桌規設定」可分別啟用順子、全紅及豹子，調整加台或豹子倍數。全紅遇上豹子可選併計或豹子優先。翻倍作用於每家應付台數，底金照原額。計台記錄會保存當時的座位、莊家與開門骰；儲存後，下局重新擲開門骰。

## 紀錄與照片

牌局和照片保存在使用者瀏覽器的 IndexedDB 中。清除網站資料或更換瀏覽器前，請先匯出文字備份。如果瀏覽器不允許持久儲存，畫面會顯示暫存模式提醒。備份可包含完整牌面照片，請自行保管。

## 執行與部署

網站採用原生 HTML、CSS 和 JavaScript 模組，無需安裝套件或執行建置。開發時在專案根目錄執行：

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000`。部署至 GitHub Pages 時，將發佈來源設為 `main` 分支的 `/ (root)`。頁面使用相對路徑，可部署在儲存庫子路徑。
